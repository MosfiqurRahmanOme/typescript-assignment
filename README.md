# TypeScript Assignment

## Introduction

This repository contains my completed TypeScript assignment, covering fundamental and advanced TypeScript concepts along with Object-Oriented Programming (OOP).

## Body

- The assignment includes practical tasks based on three major topics:

- TypeScript Foundation: Basic types, functions, arrays, objects, and interfaces.

- Advanced TypeScript: Union, Intersection, Generics, Type Narrowing, and asynchronous programming.

- OOP with TypeScript: Classes, inheritance, encapsulation, and object-oriented concepts.

- It also includes blog posts explaining important TypeScript concepts with practical examples.


## Conclusion

This assignment helped me improve my TypeScript knowledge and understand how to write structured, reusable, and type-safe code.
